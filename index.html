Welcome to Subtextual
Subtextual is a semantic writing surface for marking the intent behind your words. Assign intents to the function-key row, switch modes while typing, and export the finished text with a clean intent map. Load Defaults starts with a practical set of intent keys. Start Fresh begins with neutral keys so you can build your own setup. Colors, fonts, flavors, and patterns are visual guides only.
Reset Subtextual
Choose how much to reset. Writing Only removes editor text and generated output. Your current keys, mode, view, and shortcut setup stay in place. Reset Everything returns this session to the startup choice you selected.
About Subtextual
Subtextual Text with intent. Subtextual is a browser-based semantic writing editor for plain text, prompt drafting, scene notes, dialogue fragments, and any writing where the meaning underneath the words matters. Info
Function keys Use F1 through F8 to switch intent while writing. Wide screen mode reveals F9 and F10. Ultrawide reveals F11 and F12. Each slot has an assignable intent and a fixed visual color. Writing surface Type normally in the main editor. The active intent colors new text as you write. B, I, and U apply basic visual formatting. The semantic export cares about text and intent, not fonts or themes. File Open loads a saved Subtextual project. Save stores the current project with text, intent spans, key assignments, mode, shortcuts, and view settings. Save As exports plain text only. Reset lets you choose Writing Only or Reset Everything. Mode Freeform keeps only the editor and intent keys. Prompt adds five prompt-building shortcut buttons plus Setup. Scene adds five user-defined shortcut buttons plus Setup. View Flavors change the app color theme. Patterns change the background. Screen changes the page width and how many function keys are visible. Fonts change the editor font only. Remember me only restores visual settings: flavor, pattern, screen, and font. It does not restore your writing. Output Generate builds the semantic payload from the current writing surface. Copy places that payload on your clipboard. Clear empties the generated payload box without changing the writing surface.
Prompt Shortcuts
Choose up to five prompt labels for the shortcut row. These buttons insert reusable prompt headings at the cursor; they do not change the semantic payload by themselves.
Scene Shortcuts
Define the five scene shortcut buttons. Use them for characters, places, objects, speakers, recurring references, or any labels you type often.
